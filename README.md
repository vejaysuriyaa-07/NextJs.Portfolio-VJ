# Portfolio

My portfolio site. Next.js + Tailwind, deployed to GitHub Pages.

**Live:** https://vejaysuriyaa-07.github.io/NextJs.Portfolio-VJ/

## Run it locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Pushes to `main` deploy to GitHub Pages through GitHub Actions (`.github/workflows/deploy.yml`).
